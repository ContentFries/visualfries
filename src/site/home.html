A JSON project, and blocks when it needs them

{
  "size": [1080, 1920], "fps": 30,
  "transcript": "talk.transcript.json",
  "footage": { "talk": {
    "src": "talk.mp4", "matte": "talk.matte.mp4" } },
  "clips": [{
    "id": "depth",
    "block": "@visualfries/speaker-depth",
    "from": 0, "until": 17, "audio": "talk",
    "words": { "captions": "clip" },
    "cues": { "huge": "huge" },
    "props": {
      "words": [{ "text": "HUGE",
        "at": "huge", "hit": true }],
      "captions": { "preset": "bold" }
    }
  }]
}

Cues are phrases, not seconds. Re-record a sentence and every cue moves with the words.

Four ideas. Zero surprises.

A frame is a function of time. VisualFries sets the time, Chromium draws the DOM, ffmpeg writes the file. That is the whole trick, and it is why renders never drift.

Blocks are Svelte

Any visual is a component with props. Text is real DOM: it wraps, kerns and reflows per size. Change size and the same block becomes a 9:16, 4:5 or 16:9.

Time comes from words

A cue lands on "huge", a clip ends on "replace it". A new transcript re-times everything; a phrase that vanished fails with "Did you mean".

Deterministic frames

No timers, no CSS transitions, randomness from seeded noise. check --determinism renders sampled frames in different orders and compares them before you spend a minute on a render.

One CLI, loud failures

Built to be driven by agents: every error says what to fix. MP4, PNG stills, ProRes 4444 alpha and a manifest.json for your NLE.

doctorChecks ffmpeg, Playwright, Chromium and the toolchain.
