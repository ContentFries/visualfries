01 Document. Size, fps, background, fonts. A document is data — an agent can write it, a diff can review it.

02 Blocks. Any visual is a Svelte component with props. Text is real DOM: it wraps, kerns and reflows like on the web.

03 Time. Cues are spoken words from a transcript, not typed seconds. The static post just became a reel — same file.

04 Surfaces. Change size and the block reflows. 9:16, 1:1, 16:9 from one document; carousels are planned.

05 Render. check runs every block in seconds; render writes MP4 or ProRes 4444 alpha and a manifest for your NLE.

Where it fits

When to use VisualFries

  • You build in Svelte and want the editor and the renderer to mount the same document.
  • Timing comes from speech: transcripts, re-takes, word-level captions.
  • Agents write or repair content, so JSON plus a CLI that fails loudly beats a GUI.
  • You need alpha inserts (ProRes 4444) placed on an NLE timeline via manifest.json.

In React, Remotion is the natural choice. For framework-free HTML compositions with a GSAP timeline, HyperFrames. All three render a browser frame by frame; they differ in where the document lives and who edits it.

Start

Install, check, render.

The project above is real: download it, run four commands, get the MP4. doctor tells you what is missing before the first render.

Quickstart →Download quote.zip
$ npm install visualfries playwright
$ npx playwright install chromium             # or use an installed Chromium
$ npx visualfries doctor                      # ffmpeg, Chromium, Playwright, temp dir
$ npx visualfries clips quote.vf.json         # words → times
$ npx visualfries check quote.vf.json --determinism
$ npx visualfries still quote.vf.json --clip quote --output quote.png
$ npx visualfries render quote.vf.json --output out/
